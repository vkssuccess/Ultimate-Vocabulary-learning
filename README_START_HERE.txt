WORD VAULT — ORIGINAL STATIC WEBSITE EXPORT

This package contains the restored original version 45. The HTML, scripts, images and media are copied without content edits.

QUICK START
1. Extract the ZIP into a folder.
2. Open a terminal in that folder and run: python3 -m http.server 8000
3. Open http://localhost:8000 in your browser.

PUBLISH SEPARATELY
Upload the extracted files to the root of your chosen static website host. index.html is the entry page. Keep assets/, media/, media-v37/ and the JavaScript files in place. No framework build is required.

Word_Vault_Original.html is also supplied separately as the exact source HTML. It references the companion scripts and media, so use this complete ZIP when hosting. The HTML also remains in the ZIP as word-vault.html.

NOTES
- Fonts from Google require an internet connection; fallback fonts remain available.
- The original site stores its learning progress in browser storage; it does not include the proposed new accounts, payments, backend or cross-device tracking.
- This export does not modify or redeploy the existing live site.
- SHA256SUMS.json records the original files for integrity checking.
